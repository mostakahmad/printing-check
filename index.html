1. Connect printer

Not connected

Turn on your printer, pair it from the same PC or Android phone’s Bluetooth settings (PIN 0000 / 000000), and open this page in Google Chrome. Force-stop Thermer or any app already using the printer.

Bluetooth SPP filters to the standard Serial Port Profile (what RPP02N uses). Any serial port is a fallback for USB or already-mapped ports — on Linux it may also list ttyS* system ports (do not pick those).

Android: Need Chrome 138+. If SPP still says "No compatible devices found" after pairing and closing Thermer, run the diagnosis section. BLE visibility does not replace SPP. No webpage can bypass browser Bluetooth limits.

PC / Linux: Prefer Connect RPP02N (Bluetooth SPP). If you use Any serial port and only see ttyS0, ttyS1 etc., those are local system ports — not the printer. Pair/trust RPP02N in Linux Bluetooth settings and try SPP again.

Troubleshooting PC & Android

CHECKLIST
Verify on PC & Android (manual checklist)
  1. Printer ON, paper loaded, stay nearby.
  2. Pair in OS Bluetooth settings (PIN 0000 or 000000). Force-stop Thermer.
  3. Open this HTTPS page in real Chrome (Android needs 138+; desktop Chrome current).
  4. Tap Connect RPP02N (Bluetooth SPP) — not the BLE diagnostic.
  5. Select the printer / Serial Port Profile entry → Print sample receipt → check paper.
  6. If empty: Check browser capabilities, copy the log, then BLE diagnostic only for a verdict.
Android Chrome (138+)
  1. Pair RPP02N from Android Settings → Bluetooth.
  2. Force-stop Thermer, turn printer ON and keep it nearby.
  3. Open the HTTPS GitHub Pages URL in actual Chrome, not Facebook/WhatsApp in-app browser.
  4. Tap Connect RPP02N (Bluetooth SPP) and select the printer entry.
Windows / macOS Chrome
  1. Pair RPP02N in the computer's Bluetooth settings.
  2. Open this GitHub Pages URL in updated desktop Chrome.
  3. Use Connect RPP02N (Bluetooth SPP), not a random COM port from Any serial port.
Linux Chrome: only ttyS ports show
  1. Use the SPP button first. ttyS0 etc. (Any serial port) are not the printer.
  2. In a terminal, run bluetoothctl → scan on, then pair and trust the RPP02N address.
  3. Check the printer's Serial Port service with sdptool browse <printer-mac> if available.
  4. Refresh Chrome and try Connect RPP02N (Bluetooth SPP) again.

Chrome can use paired Bluetooth Classic SPP; it cannot guarantee every printer exposes a compatible service. Do not look for RPP02N in the BLE picker for printing. iPhone Safari is unsupported.
