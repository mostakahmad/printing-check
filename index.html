Troubleshooting PC & Android

CHECKLIST
Android Chrome (138+)
  1. Pair RPP02N from Android Settings → Bluetooth.
  2. Close Thermer, turn printer ON and keep it nearby.
  3. Open the HTTPS GitHub Pages URL in actual Chrome, not Facebook/WhatsApp in-app browser.
  4. Tap Connect and select the RPP02N / Bluetooth Serial Port entry.
Windows / macOS Chrome
  1. Pair RPP02N in the computer's Bluetooth settings.
  2. Open this GitHub Pages URL in updated desktop Chrome.
  3. Choose the printer's Bluetooth Serial Port (not a random COM port).
Linux Chrome: only ttyS ports show
  1. ttyS0 etc. are not evidence that the printer is detected.
  2. In a terminal, run bluetoothctl → scan on, then pair and trust the RPP02N address.
  3. Check the printer's Serial Port service with sdptool browse <printer-mac> if available.
  4. Refresh Chrome and try again. OS-level SPP support may need further configuration.

Chrome can use paired Bluetooth Classic serial ports; it cannot guarantee that every printer exposes a compatible SPP service. Unsupported iPhone Safari cannot use this approach.
